# さいとーの部屋

日記と音楽の記録を少しずつ置いていく、シンプルな個人サイトです。

## ページ
- `index.html` — トップページ
- `diary.html` — 日記帳
- `music.html` — 音楽棚
- `style.css` — 共通デザイン

## 運営の方針
- 誰でも読めるけれど、コメント・いいね・ランキング・アクセスカウンターは置かない。
- 日記や音楽の感想の中身はサイトの持ち主が決める。
- AIは編集・デザイン・更新の補助を行い、公開内容は持ち主が確認する。
- 下書きや個人情報は公開リポジトリに置かない。

## 公開方法（GitHub Pages）
GitHubの **Settings → Pages** で **Deploy from a branch** を選び、**main / (root)** を指定して保存すると、このリポジトリのトップページを公開できます。

公開URL（設定後）: https://kuukiyomeyo.github.io/saito-room/

※現在の日記と音楽はサンプルの文章です。実際の記事ができたら差し替えます。
